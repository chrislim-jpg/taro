### [S-01] 메인 & 일일 무료 타로 화면

#### 1) 화면 개요 및 추적성
- **화면 ID**: `S-01` (Main & Daily Tarot Screen)
- **연관 ID**: `P-01`, `F-01-01` ~ `F-01-03`, `n-01-01` ~ `n-01-05`
- **목적**: 앱의 메인 홈으로, 매일 1회 무료 타로를 뽑을 수 있는 CTA와 보유 크레딧, 심층 타로 진입 버튼 배치

#### 2) 화면 레이아웃 구조 (Wireframe Skeleton)

```
+--------------------------------------------------+
| [G-Header]  Tarotica         [💎 크레딧 15+] [⚙️] |
+--------------------------------------------------+
| [Banner] "오늘의 운세 카드 1장을 뽑아보세요!"    |
|                                                  |
|              +--------------------+              |
|              |                    |              |
|              |    [Tarot Card]    |              |
|              |   (뒷면/셔플 효과)  |              |
|              |                    |              |
|              +--------------------+              |
|                                                  |
|       [Btn] 오늘의 무료 타로 카드는? (CTA)       |
+--------------------------------------------------+
| [Card] "AI 심층 타로 리딩 받기"                    |
|        - 고민 카테고리 선택 (연애/진로/금전/관계)  |
|        - [Btn] 심층 리딩 시작하기 (크레딧 3차감) |
+--------------------------------------------------+
| [Bottom Nav]  [🏠 홈]  [📚 보관함]  [💎 상점]      |
+--------------------------------------------------+
```

#### 3) 주요 UI 컴포넌트 명세
- **G-Header**:
  - 앱 로고 (`Tarotica`) (좌측)
  - 보유 크레딧 배지 (`💎 15`): 클릭 시 `S-04` 상점 화면으로 이동
  - 설정 아이콘 (`⚙️`): 푸시 알림 설정 및 계정 관리 모달
- **Daily Tarot Section**:
  - 카드 오라클 일러스트: 오늘 미참여 시 뒷면 표시 (탭 시 1장 셔플 모션 후 앞면 전환)
  - CTA 버튼: [오늘의 무료 타로 카드는?]
    - 당일 참여 전: 활성화 상태 (`Primary Button`)
    - 당일 참여 완료 후: 비활성화 상태이며 "오늘의 카드를 확인했습니다 (내일 00:00 리셋)" 텍스트로 변경
- **Deep Reading Entrance Section**:
  - 4개 카테고리 칩 (연애 💕 / 진로 💼 / 금전 💰 / 인간관계 👥)
  - [심층 리딩 시작하기] 버튼: 크레딧 3개 소모 배지 표기
- **Bottom Navigation**:
  - [🏠 홈 (S-01)] / [📚 보관함 (S-03)] / [💎 상점 (S-04)] 3개 탭

#### 4) 5가지 화면 상태 (Screen States)
- **Normal**: 오늘의 카드 미완료 상태. [무료 타로 카드는?] 버튼 활성화.
- **Loading**: 카드 뽑기 버튼 클릭 시 1.5초간 3D 셔플 애니메이션 및 빛 효과 노출.
- **Empty**: (해당 없음)
- **Error**: 서버 통신 오류 시 "네트워크 연결을 확인해주세요" 팝업 모션.
- **Disabled**: 오늘 이미 완료한 경우 카드 앞면과 리딩 요약이 렌더링되며 버튼 비활성화.

- **질문 작성 폼 (`TextArea`)**:
  - 최소 10자 미만 입력 시 바텀 가이드 문구(경고) 및 [다음] 버튼 비활성화
  - 300자 카운팅 인디케이터
- **스프레드 인터랙션 (`Card Spread UI`)**:
  - 78장 카드 부채꼴 배치, 터치 시 상단 슬롯(1.과거 / 2.현재 / 3.미래)으로 이동 애니메이션
  - 3장 미선택 시 [결과 보기] 버튼 비활성화
- **AI 리딩 결과 뷰어**:
  - 3장 타로 카드 아트워크 정밀 렌더링
  - Markdown 지원 스트리밍/카드 형태의 섹션 구분(종합 요약, 카드별 풀이, 조언)

#### 4) 5가지 화면 상태 (Screen States)
- **Normal**: 입력 폼 작성 가능 및 카드 선택 가능 상태.
- **Loading**: [AI 리딩 보기] 클릭 후 AI 프롬프트 생성 중 상태.
  - *화면 모션*: "AI 타로 마스터가 카드를 읽고 있습니다..." 애니메이션 + 신비로운 로딩 인디케이터 (최대 15초)
- **Empty**: (해당 없음)
- **Error**: AI 응답 실패/타임아웃 발생 시
  - *화면 모션*: "리딩 생성 도중 오류가 발생했습니다. 차감된 크레딧 3개가 자동 환불되었습니다." 알림 모달 + [재시도] 버튼
- **Disabled**: 질문 글자 수(10자 미만) 미달 시 [다음] 버튼 `Disabled` 처리.
